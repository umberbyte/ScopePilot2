## 増分#3: CLI骨格 (`scopepilot simulate`)

`apps/cli` に F21 の headless CLI seed を実装した。

- `cli-parser.ts`: 未知/競合 option は usage error (exit 2)。secret と思われる option 名
  (`--token` 等) は拒否し、案内には option 名だけを出して値を log に載せない (`=` 結合形式も値を切る)。
- `exit-codes.ts`: design/19 §3 の終了code集合 (完了0・入力不正2・権限3・所見あり4・上限停止5・
  範囲違反6・engine失敗7・中断8・確認要求9)。所見の有無と実行成否を同じcodeに押し込まない。
- `output-formatter.ts`: `--json` は最終結果を stdout へ1行だけ、進捗 NDJSON は stderr のみ。
  `--events <file>` 指定時は進捗を同fileへ出す。
- `simulate.ts` + `main.ts`: 基準シナリオを固定 fixture 上で完走させ、計画hash・engine版・
  能力表fixture hash・所見件数を summary として返す。`--inject-unknown-target` で既知失敗
  (URL Does not Exist → exit 7) を再現できる。A0 は Core API HTTP の代わりに core/simulation を
  直接呼ぶ (トレーサビリティ決定「direct CLI」。HTTP契約実装時に本fileだけ差し替える)。
- UT: F21-UT-001 (parser)、F21-UT-004 (出力分離)、F21-UT-005 (exit code)、F21-UT-007 (argv secret
  拒否)、F21-UT-009 (fixture 完走と版情報) を実装した。
- 実行検証: `node apps/cli/src/main.ts simulate --json` → exit 4 (所見あり3件・監査event 16件)、
  `--inject-unknown-target` → exit 7、usage error → exit 2。`npm run typecheck`、unit 17件、FT 7件が
  すべて合格。
