## 増分: `scopepilot events` サブコマンド

- 監査 event を NDJSON で stdout へ出力。`--since N` (cursor) と `--api <url>` 対応。
  無指定時は in-process (新規 harness のため 0 行)。接続/HTTP 失敗のみ exit 7。
- parser は events command と --since (非負整数) を受理。design/19 §3 の進捗出力。
- UT: parser の --since 検証 (形式・必須値・重複)。CLI は simulate/capabilities/events の
  3 command となった。

## 増分: run 記録の永続化 (RunSinkPort) と Interrupted 検出 endpoint

- core に `RunSinkPort` を追加。`BaselineFlowService` は任意の `runSink` に
  実行開始時 (Running) と終了時 (Completed/Stopped/Failed) の RunRecord を保存する
  (design/20 §2・design/22 §6: crash 検出には Running 残置の記録が必要)。
- Core API に `GET /api/runs/interrupted` を追加。実行中残置 run を Interrupted へ
  変更して一覧を返す (自動再開しない)。未構成 server は 501。OpenAPI・経路表も同期。
- storage の `RunRepository` は構造的にこの port を満たす (save/listInterrupted/
  markInterrupted は storage IT で既に検証済み)。SQLite 接続は呼び出し側で構成する。
- UT: fake sink で探索 (Running→Completed) と診断 (Running→Completed) の保存順を検証。
  IT: `/api/runs/interrupted` が残置 Running を 1 回だけ Interrupted 化し、2 回目は空。
