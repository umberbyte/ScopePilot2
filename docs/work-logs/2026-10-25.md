# 2026-10-25 ワークフロー診断（DVWA 18分類の検出漏れ解消）

## 目的

`docs/DVWA-DETECTION-GAP-ANALYSIS.md` が挙げた検出漏れ12分類・部分漏れ2分類と、
セクション5の副ギャップ（API経由のOSコマンドインジェクション、LFI成立証拠、
SQLインジェクションのURL単位確認、オープンリダイレクトの medium/high 迂回）を
すべて自動検出できるようにする。

## 実装

- `Services/WorkflowScan/` にワークフロー診断モジュールを追加した。ZAPの単一リクエスト診断では
  届かない、複数回の状態遷移・トークン系列分析・暗号データ解析・API操作を要する脆弱性を対象とする。
  - `WorkflowScanClient` — Cookie手動管理・リクエスト数上限・証跡ログ（認証情報・一時パスワードの伏せ字化を含む）。
  - `WorkflowScanChecks` / `WorkflowScanCryptoApiChecks` — 21種のチェック。
    ブルートフォース対策(CWE-307)、CSRFパスワード変更(CWE-352)、ファイルアップロードと実行(CWE-434)、
    CAPTCHA迂回(CWE-602/489)、セッションID生成規則の特定（連番・時刻・MD5連番、CWE-330）、
    反射型・格納型・DOM型XSS(CWE-79)、CSP許可元とスクリプト取込み(CWE-693)、
    クライアント側トークン生成の再現(CWE-602)、認可不備・他利用者情報の書換え(CWE-862/639)、
    オープンリダイレクトの low/medium/high 個別確認(CWE-601)、反復XORの鍵回収(CWE-327/321)、
    AES-ECBトークンのブロック組み替えによる管理者偽造(CWE-327)、
    CBCパディングオラクルによる平文回収(CWE-203)、廃止APIの機微情報(CWE-200)、
    マスアサインメント(CWE-915)、API経由のOSコマンドインジェクション(CWE-78)、
    SQLインジェクションのURL単位成立確認（引用符・数値ペイロード×GET/POST、CWE-89）、
    LFI（絶対パス・トラバーサル・`....//` 再構成・`file://`、CWE-98/22）。
  - `WorkflowScanService` — ログイン、security.php によるレベル切替え（low/medium/high を順に実施し、
    終了後に元のレベルへ復元）、runs/workflow-*/ への実行記録（workflow-scan.json・engagement.json・workflow-summary.json）。
- パスワード変更・権限変更を伴う検証は、実施後に元の値へ復元し、復元の成否を応答テキストまたは
  別セッションでのログイン検証で確認する。DVWAのCAPTCHAモジュールはreCAPTCHAキー未設定だと
  結果表示を警告で置き換えるが変更自体は実行されるため、効果検証方式が必須だった。
- 案件設定 `DiagnosticToolSettings` に診断用アカウント（WorkflowScanUsername/Password）を追加し、
  ［診断ツールへ引き渡し］タブに「ワークフロー診断」欄（アカウント入力・実行ボタン）を設けた。
  所見は DiagnosticFinding（F-xxx）として案件へ取り込まれ、Markdown/JSON/HTML/v2 DOCX レポートへ反映される。
- `RunHistoryService` が workflow-scan モードを認識し、実行履歴へ表示する。

## 検証

- `Tests/FakeDvwaServer.cs` — DVWA互換のインプロセスサーバー（HttpListener）。18分類すべての
  脆弱な挙動と、high/impossible での保護挙動をレベル別に模倣する。実DVWAと同じ暗号仕様
  （XOR固定鍵 wachtwoord、AES-ECB 鍵はPHP opensslの16バイト切詰め、AES-CBC + PKCS7パディングオラクル）、
  CAPTCHAキー未設定時の無表示変更も再現する。
- `Tests/WorkflowScanTests.cs` 12件 — 21チェックIDの網羅検出、レベル別の暗号モジュール判定、
  セッション生成規則、LFI全レベル、SQLi URL単位、リダイレクト3実装、レベル復元、
  ログイン失敗時の安全な完了、実行履歴、レポート反映、証跡ログへの認証情報非露出、各種解析ヘルパ。
- 全テスト201件: 197合格・4スキップ（環境変数によるオプションの実機ZAP統合）・失敗0。
  以前から失敗していた同梱Playwright runtime系2件は、テスト出力先へ `@playwright/mcp` を
  npm ci で導入したことで解消した。ビルド警告0・エラー0。
- 実機検証（192.168.0.27 のDVWA、admin/password、レベルimpossible→low/medium/high→復元）:
  40件の所見を検出し、18分類すべて（bacモジュールのみ当該環境に未配布のため到達不可）を確認。
  CSRF・CAPTCHA・マスアサインメント・権限変更の復元、セキュリティレベルの復元、
  パスワードの最終確認（password で再ログイン成功）まで検証した。

## 留意点

- ワークフロー診断はDVWAクラスの挙動（user_token CSRF・security.php レベル切替え・既知の
  ゲストブック/API形状）を前提とする専用チェック群である。一般対象では各チェックは
  安全に未検出として完了する。
- 格納型XSSの検証投稿とアップロードファイル（echo 1行の無害なPHP）は対象へ1件ずつ残る
  （所見の制約欄に明記）。
