## 画面探索のAIの選択（Codex CLI / GLM（zcode））（追加記録10）

- 背景: 入力ドキュメントの補助情報抽出でGLMを選んでも、リンク巡回後の画面探索（Playwright MCPで探索ブラウザを操作する機能理解）はCodex CLI固定だった。案件設定に「画面探索のAI」を追加し、Codex CLI（既定・Codex CLIの既定モデル）またはGLM（zcode・GLM-5.3 / GLM-5.3 flash）を選べるようにした。文書を読み取るAIとは独立。Claude Code CLIは画面探索に未対応（実機未検証のため選択肢に含めない）。使ったAIはengagement.jsonの `explorationAi` へ記録する。
