# Webサービス向け脆弱性診断サービスに求められる作業・検出項目

Webアプリケーション/ Webサービスを対象とする脆弱性診断サービスにおいて、一般的に求められる作業要素と検出項目の一覧。

参照する代表的な基準:

- OWASP Top 10(2021)
- OWASP Web Security Testing Guide(WSTG)
- OWASP Application Security Verification Standard(ASVS)
- OWASP API Security Top 10
- IPA「ウェブ健康診断仕様」「安全なウェブサイトの作り方」
- CVSS(深刻度評価)

---

## 1. 作業要素(診断プロセス)

### 1.1 事前調整・合意形成

- 診断対象と範囲の確定(対象URL/IP、機能一覧、除外範囲、委譲先サービスの扱い)
- 診断規程・実施同意書の取り交わし(許可される検査行為、禁止行為、停止条件)
- 実施時期・工程の調整(本番/検証環境の別、アクセス集中時間帯の回避)
- 影響への事前対策(バックアップ取得、障害発生時の連絡・即時停止手順の共有)
- 診断用アカウントの払い出し(一般権限・管理権限、初期状態の取り決め)

### 1.2 情報収集(調査)

- 対象の全体把握:クローリングによるページ・画面遷移・パラメータの一覧化(サイトマップ作成)
- API仕様の把握(OpenAPI定義、GraphQLスキーマ、WebSocketなど)
- フィンガープリンティング(Webサーバ、フレームワーク、CMS、ライブラリの種類とバージョン)
- 公開情報の調査(検索エンジン経由の露出、公開リポジトリ、エラーページからの内部構造推測)

### 1.3 診断の設計・計画

- 検出項目の選定と対象機能へのマッピング(検査項目と画面/APIの対応表)
- 手動診断とツール診断(ZAP等)の役割分担
- ツール設定の調整(認証設定、スキャン速度、対象外パス、負荷上限)

### 1.4 診断の実施

- ツールによるスキャン(パッシブ/アクティブ)
- 手動による検証(ビジネスロジック、認可、セッション管理など自動検出が困難な領域)
- 検出結果の再現確認と誤検知の排除
- 進捗管理とインシデント対応(対象の障害・異常検知時の即時停止と連絡)

### 1.5 結果のとりまとめ・報告

- 深刻度評価(CVSS等の指標と、影響・攻撃成立条件に基づく判断)
- 再現手順の記録(リクエスト/レスポンス、入力値、証跡)
- 修正方針の提示(参考文献: 「安全なウェブサイトの作り方」等)
- 報告書の作成・納品、および対面/オンラインでの結果説明

### 1.6 再診断

- 修正された項目の再検査(修正確認と残存リスクの特定)
- 最終報告(修正状況と残存リスクの一覧)

### 1.7 証跡・品質管理

- 診断ログ・リクエスト/レスポンスの保存(追跡可能性の確保)
- 検査網羅性の記録(どの機能にどの項目を実施したか)
- 検知/誤検知の判断根拠の明示(結果の誤解を防ぐ表示)

## 2. 検出項目(脆弱性カテゴリ)

### 2.1 認証

| 項目 | 主な確認観点 |
| --- | --- |
| 総当たり攻撃(ブルートフォース) | アカウントロック、レートリミット、CAPTCHAの有無 |
| 認証の迂回 | パラメータ改ざんやレスポンス改ざんによるログイン回避 |
| パスワードポリシー | 弱いパスワード、初期パスワード・デフォルトクレデンシャル |
| パスワードリセット・再設定 | トークンの推測可能性、有効期限、情報漏えい |
| 多要素認証 | 迂回可否、再試行制限 |

### 2.2 認可・アクセス制御

| 項目 | 主な確認観点 |
| --- | --- |
| 水平権限昇格(IDOR) | 他ユーザーのデータへの直接アクセス(ID書き換え) |
| 垂直権限昇格 | 一般ユーザーによる管理機能・管理者APIへのアクセス |
| 非公開リソースへの直接アクセス | 推測可能なURL/IDによる未公開ページ・ファイルへの到達 |
| 権限ごとの画面/APIの分離 | ロールに応じた機能レベル・データレベルの制御 |

### 2.3 セッション管理

| 項目 | 主な確認観点 |
| --- | --- |
| セッショントークンの管理 | 予測可能性、ログイン前後の再生成、セッション固定化 |
| ログアウト後の処理 | サーバ側セッションの無効化、トークンの残存 |
| セッションタイムアウト | 無操作時の期限、絶対的な有効期限 |
| Cookie属性 | Secure、HttpOnly、SameSite、Domain/Pathの設定 |
| 同時セッション管理 | 多重ログイン時の古いセッションの扱い |

### 2.4 インジェクション系

| 項目 | 主な確認観点 |
| --- | --- |
| SQLインジェクション | エラー型・UNION型・ブーリアン型・時間遅延型の各手法 |
| OSコマンドインジェクション | シェルコマンド実行箇所でのメタ文字処理 |
| ディレクトリ・トラバーサル | パス名パラメータによる範囲外ファイルの参照 |
| XXE(XML外部実体) | 外部実体参照の処理、DTD読み込み |
| SSRF | サーバ側からの任意URLアクセス、内部ネットワーク到達 |
| HTTPヘッダインジェクション | CRLF挿入によるレスポンス分割、Set-Cookie/Location汚染 |
| メールヘッダインジェクション | 問い合わせフォーム等でのヘッダ操作 |
| テンプレートインジェクション(SSTI) | テンプレートエンジンへの式注入 |

### 2.5 クライアントサイド

| 項目 | 主な確認観点 |
| --- | --- |
| 反射型/格納型XSS | 出力エスケープ、属性・コンテキストごとの処理 |
| DOMベースXSS | クライアント側スクリプトのDOM操作 |
| CSRF | トークン、SameSite、Origin/Referer検証 |
| クリックジャッキング | X-Frame-Options / frame-ancestors |
| オープンリダイレクト | 外部ドメインへのリダイレクト可否 |
| 同一生成元ポリシーの許可範囲 | CORS設定の過剰な緩和、資格情報付き許可 |
| 不適切なキャッシュ制御 | 機密情報のブラウザ/プロキシキャッシュ残存 |
| postMessage・クライアント側検証 | 送信先検証、サーバ側での再検証の有無 |

### 2.6 ファイル操作

| 項目 | 主な確認観点 |
| --- | --- |
| ファイルアップロード | 実行可能ファイルの配置、拡張子/Content-Type検証、保存先の公開 |
| 任意ファイル読み書き | アップロード済みファイルの参照経路、パス制御 |

### 2.7 情報漏えい・設定不備

| 項目 | 主な確認観点 |
| --- | --- |
| エラーメッセージ | スタックトレース、DB/ミドルウェア情報の露出 |
| ソースコード・コメント | HTML/JS内の認証情報、内部構造の記述 |
| 非公開ファイルの公開 | バックアップファイル、.git、テストページ、サンプルアプリ |
| ディレクトリリスティング | 一覧表示の有効化 |
| バージョン情報 | レスポンスヘッダや既知ページからの構成情報 |
| 平文通信 | HTTPS未対応、混在コンテンツ、機密情報の平文送信 |
| TLS設定 | 弱いプロトコル/暗号スイート、証明書の有効性・鍵強度 |
| セキュリティヘッダ | CSP、X-Content-Type-Options、Referrer-Policy、HSTS 等 |

### 2.8 アプリケーション仕様・ロジック

| 項目 | 主な確認観点 |
| --- | --- |
| ビジネスロジックの不備 | 手順の省略、負数/境界値、数量・金額の改ざん、レースコンディション |
| 自動化攻撃への対策 | 大量リクエスト、ID列挙(ユーザー存在の判別可否) |
| 掲示板・投稿機能 | 不正投稿によるコンテンツインジェクション |
| 脆弱なコンポーネント | 既知脆弱性のあるライブラリ・CMS・フレームワークの利用 |

### 2.9 API固有

| 項目 | 主な確認観点 |
| --- | --- |
| BOLA/BFLA(オブジェクト/関数レベル認可) | APIの認可チェック欠如 |
| 過大なデータ露出・Mass Assignment | レスポンスの機密フィールド、意図しない属性の一括更新 |
| レートリミット・リソース消費 | バッチクエリ、ページネーション上限、コストの高い操作 |
| GraphQL | イントロスペクション公開、過剰なクエリの深さ |

### 2.10 サーバ・ネットワーク(範囲に含まれる場合)

| 項目 | 主な確認観点 |
| --- | --- |
| 公開ポート | 必要なポートのみの公開、管理ポートの外部露出 |
| 管理インターフェース | 管理画面・APIの公開範囲と認証 |

---

## 3. 報告物に求められる要素

- 診断の概要(対象、範囲、実施期間、実施者、使用ツール)
- 検出された脆弱性の一覧(深刻度、対象箇所、カテゴリ)
- 個別詳細:再現手順、リクエスト/レスポンス、影響、修正方針
- 検査網羅性の記録(項目と対象の対応表)
- 証跡の保存と参照手段

---

## 備考

- 本書は一般的なWeb向け診断サービスの要素整理であり、個別の検証対象に依存する処理や攻撃コードの作り込みを定義するものではない。
- 実際の検査では、診断規程で合意した許可範囲内で、診断ツール(ZAP等)が提供する機能の範囲を用いて実施する。
